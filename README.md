# つむぐ — 頑張らない美容の投稿スタジオ

「39歳からの頑張らない美容」をコンセプトに、7枚のInstagramカルーセルを作るツールです。ビルド・登録・APIキーは不要です。

## 使い方

1. 「文章」で美容テーマを入力し「7枚の構成案をつくる」。既存の文章は確認後に置き換えます。
2. 見出しと本文を編集。表紙1枚・解説5枚・まとめ1枚の構成です。
3. 「デザイン」でナチュラル・エレガント・シンプルを選び、色や日本語フォントを調整。
4. サムネイルでページを選び、見出し・本文サイズや揃え、文章の上下位置を調整。「この文字設定を7枚に適用」も使えます。
5. 「写真」で商品写真などをアップロード。右／下の配置と、大きさ・左右・上下位置を調整できます。
6. 「保存した投稿」で名前を付けて保存。保存した投稿の「開いて再編集」で呼び出します。同名で保存すると別のコピーが残ります。
7. PNGを個別保存、または7枚入りZIPでまとめて保存。画像は1080×1350pxです。
8. Canvaで1080×1350pxのデザインを作り、ZIPを展開したPNGを「アップロード」から読み込みます。

## 保存・写真

- 編集中の投稿はこのブラウザに自動保存します。旧版の自動保存も引き継ぎます。
- ブランド・投稿はアカウントID別にIndexedDBへ保存します。利用できない場合はエラーを表示し、書き込みを始めません。保存直前の終了に備える復旧データはアカウント別のlocalStorageを使います。
- 別端末との同期はありません。ブラウザのデータ削除やプライベートモードの終了で失われる場合があります。
- JPG・PNG・WebP、12MBまで。長辺1400px以内に縮小して端末内で処理します。アップロードした写真や文章を外部へ送信しません。
- 本文は180文字以内がおすすめ。自動縮小しても収まらない文章は「…」で省略し、画面と書き出し時に確認を表示します。

## 構成案について

外部APIを使わず、保湿・洗顔・紫外線対策・美容液・メイクのキーワードから定型文を選びます。その他のテーマは日々のスキンケアの構成になります。自由なAI生成や医療判断は行いません。入力したテーマに含まれる効果の断定表現を自動的に本文に転記しません。ご自身で編集した文章の正確性は、投稿前にご確認ください。

## SVGについて

個別・7枚ZIPのSVG出力があります。文字をテキスト、図形をベクター、写真を埋め込み画像として保存します。日本語フォントはSVGに埋め込みません。Noto Sans CJK JP / Noto Serif CJK JPを推奨します。Canvaなどの取り込み先によって文字が画像化されたり、フォントが置き換わったりするため、文字の再編集や完全な再現を保証するものではありません。見た目を保つ場合はPNGを使ってください。

## ローカル実行

このフォルダで `python -m http.server 8000` を実行し、`http://localhost:8000` を開きます。公開先はGitHub Pagesです。必要なファイルだけを公開用フォルダへコピーするワークフローを使います。

日本語フォント: Noto CJK（SIL Open Font License）。同梱のFONT-LICENSE.txtを参照してください。

## リール投稿（追加機能）

画面上部の「フィード投稿 / リール投稿」で切り替えます。共通のブラウザ保存領域で、アカウントIDと投稿種別を分けて保存します。

1. テーマ・ターゲット・15/30/60秒・目的を設定し、API不要の台本初期案を作成。
2. フック → 共感 → 気づき → 解決のヒント → 締めの5シーンを自由に編集。冒頭は最大3秒、その他の秒数も調整できます。
3. 「画像」で各シーンの写真をアップロード。縦長にトリミングし、差し替え可能。生成用プロンプトの編集・コピー・作り直しも使えます。
4. 「デザイン」でフォント・色・帯・文字サイズ・位置・揃え・アニメーションを設定し、名前付きテンプレートとして保存。
5. 「音声」でナレーションとBGMを追加。利用許諾確認にチェックしたBGMのみ使用します。音源は同梱していません。ファイル各20MBまで。
6. 「再生」でプレビュー、シークバーで確認。編集中のリールは写真・音声込みでこのブラウザに保存されます。
7. 「CapCut用素材をZIP保存」。背景画像5枚・透明テロップ5枚・合成画像5枚・台本・CSV・SRT・画像プロンプト・設定JSON・説明書を出力。設定したナレーションと利用許諾確認済みBGMも含めます。CapCutでは説明書とCSVに沿って手動で配置してください。
8. MP4出力には付属のローカルサーバーが必要です。[サーバーの使い方](server/README.md)を参照してください。

## リール台本テンプレートの改善

「台本」で目的（保存・フォロー・コメント）、冒頭タイプ（意外性・共感・疑問）、投稿タイプ（美容知識・悩み解決・体験談・商品紹介）を選べます。従来の「役立つ情報を伝える」は旧設定として保持します。

- 「編集用の5シーン台本を作る」で、確認後に台本を置き換えます。写真・音声・デザインは残します。台本を変更した場合はアップロード済み音声との一致も確認してください。
- A/B/Cのフック候補は、第1シーンだけに反映します。テロップとナレーションは別々に編集できます。
- 「最近なんか老けた？」は鏡の照明・角度、「忙しい朝の保湿」は商品の使用方法・前夜の準備、「美容液の選び方」は相性の判断・予算・使用頻度を中心にした編集用テンプレートです。
- 未対応のテーマでは、確認済み情報と具体的な方法を入力してください。医学的な内容や未知のテーマを推測して補うことはありません。
- 体験談は困っていたこと・試したこと・感じたことと条件を本人が入力します。未入力の経験を作らず、編集箇所として表示します。
- 商品紹介は商品名と確認済みの商品情報を入力します。未入力の効果や使用感は補いません。
- PR・広告・商品提供の表示は、リール全シーンのプレビュー・字幕画像・合成画像・SRTに反映します。関係がある場合は適切な表示を選んでください。
- 未入力箇所、断定表現の一部、ナレーションの長さの目安を画面で知らせます。自動の事実確認や法的判断ではないため、入力した文章の正確性と表示は投稿前に確認してください。
- ZIPのscript.txt・captions.srt・settings.jsonに編集内容が反映され、script-notes.txtには入力した情報・出典メモと確認事項を収録します。
- 旧データでは新しい設定の初期値だけを補い、既存の台本・素材・テンプレートを引き継ぎます。

台本処理は `reel-script-templates.js` に独立しています。`generate(settings)` は5シーン、`hooks(settings)` は3つのフック候補、`warnings(scenes)` は編集時の確認メッセージを返します。DOM・保存・通信を扱わず、将来のプロバイダー差し替えに備えた境界です。外部AI APIは接続していません。ターゲット欄の一部のキーワードで定型文を選び分けますが、自由な推論や対象者分析はしません。

台本モジュールのテストは `node tests/reel-script-templates.cjs` で実行できます。指定3テーマ・2種類の情報系投稿・3尺・3フック・3目的の162通りに加え、未対応テーマ、入力事実の保持、体験の非捏造、商品情報、確認メッセージを検証します。

## アカウント・ブランド管理（ローカル保存）

1. 上部の「制作するアカウント」で、美容アカウント／飲食店アカウントを選びます。
2. 「ブランド設定・投稿一覧」を開き、名前・アイコン・ジャンル・ターゲット・世界観・3〜5色・フォント・テンプレート・トーン・禁止表現・目的・CTAを保存します。
3. 保存したブランド設定は新規投稿に適用します。既存の投稿の文字・素材・色は書き換えません。トーンと禁止表現は制作ガイドとして表示し、自動校正は行いません。
4. フィードは従来の「保存した投稿」、リールは台本画面の「名前を付けてリールを保存」から下書きを残します。管理画面の投稿一覧からも再編集できます。
5. バックアップは現在のアカウントだけ、または全アカウントのJSONをダウンロードできます。写真・音声・下書き・テンプレートも含みます。ブランド設定は保存ボタンで確定した内容が対象です。
6. インポートは100MB以下のつむぐJSON。既存データを上書きせず、新しいIDのアカウントとして追加します。元ファイルのアカウントIDと投稿の所属が一致しないファイルは拒否します。
7. アカウントを削除すると、新しい保存領域内のブランド・投稿・写真・音声・テンプレート・復旧データを削除します。移行元の旧保存データ、ダウンロード済みファイルは残ります。最後の1アカウントは削除できません。

旧データは初回起動時に美容アカウントへコピーします。旧IndexedDB・旧localStorageを削除せず、全コピーと移行完了記録を1トランザクションで保存します。失敗した場合は操作を止め、元データを保持します。移行には元データ分の追加容量が必要です。

切替前に編集中のフィードとリールの保存を待ちます。失敗時は切替を中止し、書き出し・読み込み処理中も切替を受け付けません。保存失敗中の投稿は、エクスポート時にメモリ上の編集内容を含めて退避できます。その場合もブラウザ保存の失敗を成功とは表示しません。

**ログイン認証・暗号化・クラウド同期はありません。** 共用端末では使用せず、機密性の高い情報を入力しないでください。バックアップも暗号化されません。ブラウザのデータ削除・端末故障・容量不足・OSやブラウザの強制終了に備え、定期的にエクスポートしてください。公開サイトのソースコードへ、入力したブランド情報や写真を送る処理はありません。従来のローカルMP4サーバーを使う場合のみ、確認後に現在のリール素材をそのサーバーへ送ります。

詳細な保存構成と次段階の境界は [ローカル保存の設計と制限](LOCAL-STORAGE.md) を参照してください。

## 無料の写真制作補助

- フィードの「写真」、リールの「画像」で写真スタイルを選び、「文章/台本から作る」を押すと、選択ページ/シーンの文章に基づく編集用プロンプトと構図案を作ります。外部AIではなく、端末内のルールによる補助です。プロンプトは編集・コピーできます。画像自体の生成は未接続です。
- PNG・JPEG・WebPを12MBまで取り込み可能。ヘッダーとMIME形式、画像のデコード、4000万画素以下を検証します。取り込み後は端末内で縮小します。
- フィードは写真の配置・大きさと切り抜き比率/拡大/左右/上下、リールは9:16枠内の拡大/左右/上下を調整できます。元画像を保持し、切り抜きリセットが可能です。文字は既存デザイン画面で別に編集します。
- フィードは1080×1350のPNG/SVG/ZIP、リールは選択シーン1080×1920のPNGと既存CapCut素材ZIPに調整内容を反映します。フィード全体の出力比率は4:5、リールは9:16で固定です。写真枠の比率とは別です。
- スタイル・編集済みプロンプト・切り抜きは所属アカウントの投稿に保存します。構図案は作成時に表示し、同内容がプロンプトにも含まれます。旧データに追加設定がなければ従来の表示を維持します。
- `image-tools.js` は通信・保存・DOMに依存しないプロンプト/切り抜き処理とローカルファイル検証です。将来のAI接続は別プロバイダーとして追加し、この処理へAPIキーを置かない設計です。今回の追加機能は画像の外部送信を行いません。既存MP4サーバーへの確認付き送信の仕様は変更していません。
- `node tests/image-tools.cjs` でプロンプト・切り抜き境界・形式不正ファイルの検証を実行できます。

JPEGも保存できます。フィードはプレビュー上部の「この1枚のJPEG」、下部の「7枚のJPEGをZIP保存」、リールは「選択シーンのJPEG」を使います。PNGの寸法と同じで、JPEGは品質92%（リール90%）の非可逆圧縮です。写真と文字を再編集するには、ブラウザ保存またはJSONバックアップを利用してください。

当面1人で利用する前提です。ログイン機能は今回追加していません。公開URLでも、投稿データは利用中のブラウザに保存されます。将来の本人認証・予算上限・重複課金対策はFUTURE-IMAGE-API.mdに設計として記載しており、API接続は未実装です。

## フィード写真の自由配置

新しく取り込む写真は大きめに中央配置されます。プレビューの写真をクリック/タップして選択し、ドラッグで移動、四隅のハンドルで比率を保って拡大縮小できます。写真操作中はスクロールとアカウント切替を抑止します。写真は1ページ1枚で、文字は独立したまま前面に重なります。

選択するとプレビュー下にX/Y・幅/高さ・拡大率、ページいっぱい、中央配置、背景写真、取り消し、配置リセットが表示されます。キーボードの矢印（Shiftで10px）、Escapeで操作中断にも対応。数値入力は変更を確定すると反映します。ページ外へはみ出した部分はプレビュー・PNG/JPEG/SVGとも切り抜かれ、選択枠は出力されません。

旧写真は従来どおり表示します。移動/拡縮/配置ボタンを初めて使った時だけ、その時点の矩形を保って自由配置へ切り替えます。旧右/下配置用の文字幅も引き継ぎ、以後の写真移動で文字の位置を変えません。新しい写真は全文字幅を使います。トリミング設定は「写真」パネルで調整します。

写真内の任意項目placement/placementReset（version 1、id、type、layer、x/y/width/height、textFlow）で配置とリセット基準を保存します。既存の画像data URI、framing、アカウント別DBは維持。描画・出力・ヒット判定が同じ矩形を使う構成で、将来の複数レイヤーに備えて種類とIDを持たせています。現在の写真枚数や保存DBスキーマは変更していません。詳細はTEST-FREE-PHOTO.mdを参照してください。

## フィード見出しの自由編集

プレビューの見出し、または「見出しを選択して自由に編集」を押すと、青い選択枠と編集ツールが表示されます。ドラッグで移動、四隅で縦横比を保って文字枠と文字サイズを一緒に拡大縮小します。左右中央のハンドルは文字サイズ・高さを変えずに枠の幅だけを変更し、文章を折り返します。枠の幅/高さは数値で、文字サイズは数値/スライダーでも個別に変更できます。四隅の拡大縮小は文字16〜180px・既存の枠サイズ/字間の上限で止まります。ゴシック/明朝、太さ、色、揃え、行間、字間、文字/背景の不透明度、背景色、影、写真との前後関係に対応しています。

写真を選択すると文字ツールが閉じ、文字を選択すると写真ツールが閉じます。写真で隠れた背面文字は選択ボタンから編集してください。文字の矢印移動、Escapeでドラッグ中断、見出しの取り消し、配置・書式リセットも利用できます。PNG/JPEG/SVGは表示と同じ設定を使い、編集用の枠/ハンドルは出力しません。

見出しは各ページ1要素（70文字）です。本文の自由編集は下記の専用欄、リールは従来の編集を使います。自由設定がない旧投稿は従来表示を維持し、編集開始時にslide.headingLayerを任意項目として追加します。文章自体は従来のslide.titleです。自由編集後は文字を自動縮小せず、枠外を切り抜いて警告します。配置・書式リセットは文章を残し、従来の自動配置へ戻します。新設定の保存/再編集/バックアップ復元を検証済みです。詳細と制限はTEST-FREE-HEADING.md、拡大縮小の操作と検証はTEST-HEADING-RESIZE.mdをご覧ください。

## フィード本文の自由編集

本文もプレビュー上でクリック/タップして自由に編集できます。「本文を選択して自由に編集」からも選べます。四隅は文字サイズと枠を同じ倍率で拡縮、左右中央は文字サイズを変えずに枠の幅だけを変更します。移動・数値/スライダー・フォント・太さ・色・揃え・行間・字間・透明度・背景帯・影・写真との前後関係を調整できます。

見出しと本文が重なって選びづらい場合は、それぞれの選択ボタンで切り替えてください。設定と取り消しは独立し、写真操作で文字位置は変わりません。本文は従来の文章タブからも編集でき、400文字の上限を維持します。リセットは文章を残して従来レイアウトに戻します。

任意のslide.bodyLayerに本文の書式/配置を保存し、文章は従来のslide.bodyを使います。旧投稿は本文を自由編集するまで同じ見た目を保ちます。名前付き保存・再読み込み・JSONバックアップ復元・アカウント分離・PNG/JPEG/SVG出力に対応。詳細と未検証項目はTEST-FREE-BODY.mdを参照してください。

## 商品紹介リール：動画カット編集（第1段階）

「動画カット編集」タブでMP4や対応MOVを複数取り込み、可変カットを作成できます。素材のサムネイルと秒数を確認し、カードのドラッグ（PC）または↑/↓で順番を変更してください。カットを選び、開始/終了秒数・表示方法・拡大・左右/上下位置を調整します。素材の「カットに追加」やカットの「複製」で同じ素材を繰り返し使えます。9:16の連続プレビュー、再生/一時停止・停止・全体シークに対応し、元音声をそのまま再生します。切替時には短い読み込み待ちが入る場合があります。

第1段階にはテロップ・音声編集・MP4書き出しを含みません。既存の5シーン台本・CapCut ZIPとは別のプロジェクトです。

保存先は既存のアカウント別IndexedDBです。動画はvideo名前空間のassetレコードにBlobとして保存し、projectレコードは素材IDとカット情報のみを保持します。DBスキーマや既存feed/reelデータを初期化しません。取り込み時は素材と編集情報を同一トランザクションで保存し、容量不足などで中断した場合は両方をロールバックします。名前付き下書きは同じ素材を共有します。「未使用の素材を削除」は現在の編集とすべての動画下書きから参照されていない素材だけが対象です。

無料のブラウザ機能だけを使います。1素材25MiB・5分・各辺4096px以下、1アカウント30素材/合計50MiB、60カット・全体10分、名前付き下書き100件までです。MOVはftypヘッダーを持ち、このブラウザがデコードできるものに限ります。H.264/SDR/1080pを推奨し、HEVC/HDR・旧MOV等の互換性は保証しません。アプリの上限以内でもブラウザの容量・メモリ制限で失敗する場合があります。

**動画の元ファイルもPC等に保管してください。** ブラウザデータの削除・自動退避・プライベートモード終了・端末故障で素材と編集情報が消える可能性があります。保存の保護申請（StorageManager.persist）は許可されない場合があり、完全な保護ではありません。編集中の保存に失敗した場合は、再読み込みせずJSONバックアップで退避します。タブ終了直前に必ず保存できる保証はありません。

通常のアカウントJSONに動画も含められます。Base64化で約1.34倍になるため、100MBを超える場合はアカウント別に保存するか、「動画専用JSON」と動画を除いた通常JSONに分けてください。動画専用JSONはブランド・動画素材・動画下書き・現在の編集のみを含み、フィード/5シーン台本を含みません。いずれも「ブランド設定・制作データ」のインポートから**新しいアカウント**へ復元します。分割ファイルを既存アカウントへ上書き統合する機能はありません。バックアップは非暗号化で、動画の元音声や元ファイルの撮影メタデータも含みます。

動画編集は外部サーバーへ素材を送信せず、URL/クラウド同期/APIキー/有料サービスを使いません。旧コードへ戻して動画を含むバックアップを読むことはできません。公開前の開発ブランチではmainのマージ・Pages更新を行いません。実装・検証詳細：TEST-PRODUCT-REEL.md。
