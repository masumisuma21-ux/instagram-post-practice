# つむぐ — 頑張らない美容の投稿スタジオ

「39歳からの頑張らない美容」をコンセプトに、7枚のInstagramカルーセルを作るツールです。ビルド・登録・APIキーは不要です。

## 使い方

1. 「文章」で美容テーマを入力し「7枚の構成案をつくる」。既存の文章は確認後に置き換えます。
2. 見出しと本文を編集。表紙1枚・解説5枚・まとめ1枚の構成です。
3. 「デザイン」でナチュラル・エレガント・シンプルを選び、色や日本語フォントを調整。
4. サムネイルでページを選び、見出し・本文サイズや揃え、文章の上下位置を調整。「この文字設定を7枚に適用」も使えます。
5. 「写真」で商品写真などをアップロード。右／下の配置と、大きさ・左右・上下位置を調整できます。
6. 「保存した投稿」で名前を付けて保存。保存した投稿の「開いて再編集」で呼び出します。同名で保存すると別のコピーが残ります。
7. PNGを個別保存、または7枚入りZIPでまとめて保存。画像は1080×1350pxです。
8. Canvaで1080×1350pxのデザインを作り、ZIPを展開したPNGを「アップロード」から読み込みます。

## 保存・写真

- 編集中の投稿はこのブラウザに自動保存します。旧版の自動保存も引き継ぎます。
- 写真を含む投稿はIndexedDBに保存。利用できない場合はlocalStorageを試し、保存に失敗した場合は画面に表示します。
- 別端末との同期はありません。ブラウザのデータ削除やプライベートモードの終了で失われる場合があります。
- JPG・PNG・WebP、12MBまで。長辺1400px以内に縮小して端末内で処理します。アップロードした写真や文章を外部へ送信しません。
- 本文は180文字以内がおすすめ。自動縮小しても収まらない文章は「…」で省略し、画面と書き出し時に確認を表示します。

## 構成案について

外部APIを使わず、保湿・洗顔・紫外線対策・美容液・メイクのキーワードから定型文を選びます。その他のテーマは日々のスキンケアの構成になります。自由なAI生成や医療判断は行いません。入力したテーマに含まれる効果の断定表現を自動的に本文に転記しません。ご自身で編集した文章の正確性は、投稿前にご確認ください。

## SVGについて

個別・7枚ZIPのSVG出力があります。文字をテキスト、図形をベクター、写真を埋め込み画像として保存します。日本語フォントはSVGに埋め込みません。Noto Sans CJK JP / Noto Serif CJK JPを推奨します。Canvaなどの取り込み先によって文字が画像化されたり、フォントが置き換わったりするため、文字の再編集や完全な再現を保証するものではありません。見た目を保つ場合はPNGを使ってください。

## ローカル実行

このフォルダで `python -m http.server 8000` を実行し、`http://localhost:8000` を開きます。公開先はGitHub Pagesです。必要なファイルだけを公開用フォルダへコピーするワークフローを使います。
