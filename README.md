# つむぐ — 頑張らない美容の投稿スタジオ

「39歳からの頑張らない美容」をコンセプトに、7枚のInstagramカルーセルを作るツールです。ビルド・登録・APIキーは不要です。

## 使い方

1. 「文章」で美容テーマを入力し「7枚の構成案をつくる」。既存の文章は確認後に置き換えます。
2. 見出しと本文を編集。表紙1枚・解説5枚・まとめ1枚の構成です。
3. 「デザイン」でナチュラル・エレガント・シンプルを選び、色や日本語フォントを調整。
4. サムネイルでページを選び、見出し・本文サイズや揃え、文章の上下位置を調整。「この文字設定を7枚に適用」も使えます。
5. 「写真」で商品写真などをアップロード。右／下の配置と、大きさ・左右・上下位置を調整できます。
6. 「保存した投稿」で名前を付けて保存。保存した投稿の「開いて再編集」で呼び出します。同名で保存すると別のコピーが残ります。
7. PNGを個別保存、または7枚入りZIPでまとめて保存。画像は1080×1350pxです。
8. Canvaで1080×1350pxのデザインを作り、ZIPを展開したPNGを「アップロード」から読み込みます。

## 保存・写真

- 編集中の投稿はこのブラウザに自動保存します。旧版の自動保存も引き継ぎます。
- 写真を含む投稿はIndexedDBに保存。利用できない場合はlocalStorageを試し、保存に失敗した場合は画面に表示します。
- 別端末との同期はありません。ブラウザのデータ削除やプライベートモードの終了で失われる場合があります。
- JPG・PNG・WebP、12MBまで。長辺1400px以内に縮小して端末内で処理します。アップロードした写真や文章を外部へ送信しません。
- 本文は180文字以内がおすすめ。自動縮小しても収まらない文章は「…」で省略し、画面と書き出し時に確認を表示します。

## 構成案について

外部APIを使わず、保湿・洗顔・紫外線対策・美容液・メイクのキーワードから定型文を選びます。その他のテーマは日々のスキンケアの構成になります。自由なAI生成や医療判断は行いません。入力したテーマに含まれる効果の断定表現を自動的に本文に転記しません。ご自身で編集した文章の正確性は、投稿前にご確認ください。

## SVGについて

個別・7枚ZIPのSVG出力があります。文字をテキスト、図形をベクター、写真を埋め込み画像として保存します。日本語フォントはSVGに埋め込みません。Noto Sans CJK JP / Noto Serif CJK JPを推奨します。Canvaなどの取り込み先によって文字が画像化されたり、フォントが置き換わったりするため、文字の再編集や完全な再現を保証するものではありません。見た目を保つ場合はPNGを使ってください。

## ローカル実行

このフォルダで `python -m http.server 8000` を実行し、`http://localhost:8000` を開きます。公開先はGitHub Pagesです。必要なファイルだけを公開用フォルダへコピーするワークフローを使います。

日本語フォント: Noto CJK（SIL Open Font License）。同梱のFONT-LICENSE.txtを参照してください。

## リール投稿（追加機能）

画面上部の「フィード投稿 / リール投稿」で切り替えます。既存フィードとは独立したIndexedDB領域に編集中のリールを保存します。

1. テーマ・ターゲット・15/30/60秒・目的を設定し、API不要の台本初期案を作成。
2. フック → 共感 → 気づき → 解決のヒント → 締めの5シーンを自由に編集。冒頭は最大3秒、その他の秒数も調整できます。
3. 「画像」で各シーンの写真をアップロード。縦長にトリミングし、差し替え可能。生成用プロンプトの編集・コピー・作り直しも使えます。
4. 「デザイン」でフォント・色・帯・文字サイズ・位置・揃え・アニメーションを設定し、名前付きテンプレートとして保存。
5. 「音声」でナレーションとBGMを追加。利用許諾確認にチェックしたBGMのみ使用します。音源は同梱していません。ファイル各20MBまで。
6. 「再生」でプレビュー、シークバーで確認。編集中のリールは写真・音声込みでこのブラウザに保存されます。
7. 「CapCut用素材をZIP保存」。背景画像5枚・透明テロップ5枚・合成画像5枚・台本・CSV・SRT・画像プロンプト・設定JSON・説明書を出力。設定したナレーションと利用許諾確認済みBGMも含めます。CapCutでは説明書とCSVに沿って手動で配置してください。
8. MP4出力には付属のローカルサーバーが必要です。[サーバーの使い方](server/README.md)を参照してください。

### 実装状況

- 実装済み：リール画面、API不要の定型台本補助、編集、画像アップロード、テンプレート、音声追加、フェード/ズーム、プレビュー、CapCut素材ZIP、ローカルサーバー経由のMP4。
- 未実装：外部AIによる台本生成、AI画像の生成/再生成、ナレーション自動生成、動画ファイルの取り込み・カット編集、CapCutプロジェクト直接読み込み。
- GitHub Pages上のMP4出力はサーバー未接続として無効化。WebMをMP4と呼び換える処理はありません。
- 有料API・外部ライブラリ・クラウド契約は追加していません。
- ターゲットは保存し、一部のキーワードで台本を選び分けます。定型文の対象外の内容を自動推論する機能はありません。
- プレビューは端末性能によりフレームが間引かれることがあります。サーバー出力は30fpsで処理します。

## リール台本テンプレートの改善

「台本」で目的（保存・フォロー・コメント）、冒頭タイプ（意外性・共感・疑問）、投稿タイプ（美容知識・悩み解決・体験談・商品紹介）を選べます。従来の「役立つ情報を伝える」は旧設定として保持します。

- 「編集用の5シーン台本を作る」で、確認後に台本を置き換えます。写真・音声・デザインは残します。台本を変更した場合はアップロード済み音声との一致も確認してください。
- A/B/Cのフック候補は、第1シーンだけに反映します。テロップとナレーションは別々に編集できます。
- 「最近なんか老けた？」は鏡の照明・角度、「忙しい朝の保湿」は商品の使用方法・前夜の準備、「美容液の選び方」は相性の判断・予算・使用頻度を中心にした編集用テンプレートです。
- 未対応のテーマでは、確認済み情報と具体的な方法を入力してください。医学的な内容や未知のテーマを推測して補うことはありません。
- 体験談は困っていたこと・試したこと・感じたことと条件を本人が入力します。未入力の経験を作らず、編集箇所として表示します。
- 商品紹介は商品名と確認済みの商品情報を入力します。未入力の効果や使用感は補いません。
- PR・広告・商品提供の表示は、リール全シーンのプレビュー・字幕画像・合成画像・SRTに反映します。関係がある場合は適切な表示を選んでください。
- 未入力箇所、断定表現の一部、ナレーションの長さの目安を画面で知らせます。自動の事実確認や法的判断ではないため、入力した文章の正確性と表示は投稿前に確認してください。
- ZIPのscript.txt・captions.srt・settings.jsonに編集内容が反映され、script-notes.txtには入力した情報・出典メモと確認事項を収録します。
- 旧データでは新しい設定の初期値だけを補い、既存の台本・素材・テンプレートを引き継ぎます。

台本処理は `reel-script-templates.js` に独立しています。`generate(settings)` は5シーン、`hooks(settings)` は3つのフック候補、`warnings(scenes)` は編集時の確認メッセージを返します。DOM・保存・通信を扱わず、将来のプロバイダー差し替えに備えた境界です。外部AI APIは接続していません。ターゲット欄の一部のキーワードで定型文を選び分けますが、自由な推論や対象者分析はしません。

台本モジュールのテストは `node tests/reel-script-templates.cjs` で実行できます。指定3テーマ・2種類の情報系投稿・3尺・3フック・3目的の162通りに加え、未対応テーマ、入力事実の保持、体験の非捏造、商品情報、確認メッセージを検証します。
