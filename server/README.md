# リールのMP4生成（ローカル専用）

GitHub Pagesは静的ホスティングのため、このPythonサーバーは動きません。GitHub Pagesの画面では、台本・画像・プレビュー・CapCut素材ZIPを使えます。

## MP4を作る手順

1. このリポジトリを「Code → Download ZIP」で取得し、展開します。
2. PCにPython 3.10以上とFFmpegを導入します。`python --version`、`ffmpeg -version`、`ffprobe -version`で確認してください。FFmpegにはlibx264とAACエンコーダーが必要です。
3. 展開したフォルダでターミナルを開き、次を実行します。

```sh
python server/reel_server.py
```

4. ブラウザで **http://127.0.0.1:8000** を開きます。リール画面に「MP4生成サーバーに接続済み」と出ます。
5. 素材を設定して「MP4を書き出す」。素材をローカルサーバーへ送る確認が出たら内容を確認します。
6. 終了するときはターミナルでCtrl+C。

追加のPythonパッケージ・APIキー・有料サービスは不要です。別ポートは `python server/reel_server.py --port 8001`。

**公開URLとローカルURLの保存データは別です。** 現状、GitHub Pagesの保存データを自動同期する機能はありません。MP4を作る場合はローカルURLでリールを編集してください。スマートフォンではGitHub Pagesの素材ZIPを使ってCapCutで編集するのが簡単です。

## 出力と制限

- 1080×1920 / 30fps / H.264 / yuv420p / AAC 48kHzステレオ / MP4 faststart
- 5シーン、冒頭は最大3秒。各シーンは0.5秒以上、30fpsのフレーム単位。
- 背景画像をズーム、テロップは固定。フェードは先頭・末尾0.3秒（短いシーンは調整）。切替はカットです。
- ナレーションは動画先頭から。BGMは繰り返し、動画長で終了。音量を反映してミックスします。
- 音声未設定でも無音のAACトラックを付けます。
- 画像は背景JPEGと透明テロップPNGとしてブラウザで作り、送信します。
- リクエスト合計100MB、音声各20MB、同時生成1件。長い動画はPCの性能により数分かかります。
- 一時ファイルは処理終了時に削除します。音声・写真・台本をログへ出力しません。

## 公開サーバーについて

この実装は127.0.0.1だけで待ち受けるローカル専用です。インターネット向けの共有サーバーとしてそのまま公開しないでください。公開運用には、TLS・利用者認証・レート制限・容量/実行時間制限・ジョブ管理・保存期間の設定が別途必要です。

既存のGitHub PagesのURLや配信設定は変更していません。クラウドサーバーの契約・デプロイは行っていません。
